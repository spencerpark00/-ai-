# MRO Copilot — 서비스 디벨롭 정리본

> 항공정비 Physical AI 오케스트레이션 PoC. **정비사 현장 앱 + 관리자 관제 콘솔**을 지식그래프(Neo4j)와 연결하고, 작업 결과가 다시 지식으로 축적되는 순환까지 구현.
> 라이브: **https://mro-copilot.onrender.com**

---

## 0. 전체 구조

```
[정비사 현장 앱]  ─판정/진행 보고→  [Node 서버]  ─읽기/쓰기→  [Neo4j Aura 지식그래프]
   (모바일·다크)                     (공유 상태·환류)              (검증사례 영구 축적)
        │                                 │
   대화형 AI 챗봇                    [관리자 관제 콘솔]  ←  Gemini(LLM)
   (Gemini+RAG+현장용어)              (데스크톱·라이트)
```

- 로그인 랜딩에서 **역할(관리자/정비사) + 정비사 본인**을 골라 각 화면으로 진입
- 두 화면은 직접 연결이 아니라 **서버를 통해** 연결 (정비사 판정 → 관리자 실시간 반영 → Neo4j 환류)

## 1. 정비사(작업자) 현장 앱

**본인 계정 로그인** — 정비사 5명(박재현·이수민·최동욱·김하늘·한지원, 각자 로봇 MR-01~05) 중 선택. **자기에게 배정된 작업만** 표시(1인 8건) → 정비사마다 목록이 다름.

**작업 5단계 흐름**
1. 오늘의 작업 — 위험도(🔴긴급/🟠주의/🟢정상)와 함께 목록
2. 작업 받기 — 기체·부위·위험도 확인
3. 로봇 촬영 — 사각지대 로봇 촬영 / 직접 촬영
4. AI 결과 — 이상 후보 박스 표시(예: CORROSION 0.87) + 근거 드릴다운
5. 판정·기록 — **정비사가 정상/재검사/수리 직접 판정** → 자동 기록

- **각 단계를 넘길 때마다 관리자 가동보드에 실시간 반영** (단계·경과·로봇상태)
- 배정 작업 다 하면 **"새 작업 배정받기"** 로 이어서
- **대화형 AI 챗봇** — Gemini(LLM) + RAG(Neo4j·FAA 교범 근거) + 현장용어("메가네"→링렌치) + 대화 기억. 근거 밖은 지어내지 않음

## 2. 관리자 관제 콘솔 — MRO OPS CENTER

사내 SSO 로그인 후 좌측 메뉴 전환. **정비 공정 관리자**(정시출발 권한 밖) 관점 — "지금 무엇을 승인·개입·보완할지".

### 운영 (Operations)
- 오늘 카운터(전체/완료/대기/긴급)
- **가동 보드** — 정비사·로봇 5쌍 단계·경과·로봇상태. **실제 상태만 반영 → 정비사 화면과 100% 일치.** 로그인해 근무 중이면 '작업중' 세션 유지, 로그아웃/유휴 시 '대기' 복귀
- **데모 자동재생** 토글 — 혼자 시연 시 미로그인 정비사가 실제 작업을 자동 진행(일치 유지, 환류 미기록)
- 승인 대기큐 / 검사 로봇 현황(촬영·이동·대기·충전) / 활동 이력
- **AI 운영 제안 → 클릭 시 판단 근거 Drawer**(유사 사례·대기·병목확률·Neo4j 근거·신뢰도, 실측/Neo4j/추정 라벨). 관리자 판단(참고/무시/우선처리)은 활동 이력에 기록. AI는 제안까지, 실행은 관리자

### 품질 (Quality) — "새는 곳을 지금 막는다"
- **증빙 완결성 감시(핵심)** — 완료 작업의 사진·판정·조치·기록 4증빙 완결률 + 미달 목록 + '지식에서 보기'. **KPI(증빙 자동 연결률 95%↑)와 직결**
- 재검사·재촬영(실데이터) / 반려·수정 사유 / 정비 지식 축적(결함 Top·규모)

### 인재 (People) — "지원·배분 판단"
- **숙련도별 부하 분포** — 등급별 평균 미완료 vs 권장 상한, 과부하 표시(실집계)
- **정비사별 현황** — 5명 완료/대기/재검사/상태, 과부하·유휴 플래그
- **AI 신입 지원 제안** — 신입 대상 지식그래프 검증사례 연결 추천
- 개인 평가 아님 · 위치/생체 추적 없음

### 지식 (Knowledge) — "환류를 실물로 확인"
- 케이스 브라우저(읽기 전용, Neo4j) — 검증사례(환류) + FAA 외부사례
- 출처·완결성 필터, **연결 완결성 4배지**(사진·판정·조치·지시)
- 사례 클릭 → **담당 정비사(등급·로봇)** + **결함별 실사진**(부식·균열·찍힘 실사진, 사례마다 다름 / 마모는 스키매틱) + 판정·촬영출처·연결 문서

### 효과 리포트 (심의·시연 전용)
리드타임·재작업률·검증사례 누적 등 전/후 지표. 금액·ROI 미표시.

## 3. 실시간 연동 + 환류(순환)

```
정비사 판정 ─실시간→ 관리자 가동보드·활동이력 (4초 폴링)
정비사 승인 ─쓰기→ Neo4j VerifiedCase 축적 (담당 정비사·결함·촬영방법 포함)
```

- **환류는 Neo4j에 영구 저장** — 운영 탭(메모리·재시작 시 리셋)과 달리 계속 쌓임. "작업할수록 지식이 쌓인다"의 실구현
- 검증 지식은 **사람 승인만** 등록(HITL) — 자동재생 완료분은 미기록
