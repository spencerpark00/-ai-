## 4. ⚠️ 삽질 기록 — Aura 접속 시 반드시 알아야 할 것

`Invalid credential` 에러가 계속 났는데 **비밀번호 문제가 아니었습니다.**

**원인: `NEO4J_DATABASE` 누락**

Neo4j Aura는 **URI · USER · DATABASE 세 값이 모두 인스턴스 ID**입니다.
`NEO4J_DATABASE`를 빠뜨리면 기본값 `neo4j`로 접속하는데, 그때 Neo4j가
"DB 없음"이 아니라 **"Invalid credential"로 응답**해서 비밀번호 문제로 오인하게 됩니다.

올바른 환경변수 4개:
```
NEO4J_URI      = https://15e646bf.databases.neo4j.io
NEO4J_USER     = 15e646bf
NEO4J_DATABASE = 15e646bf      ← 이게 빠지면 인증 실패로 보임
NEO4J_PW       = (Render 환경변수 값)
```

이 내용은 `seed/run_cypher.js` 상단 주석에도 기록해뒀습니다.
