# D-008 시뮬레이션 시나리오 v1 — PyBullet 블레이드 검사 촬영

> 목적: PyBullet로 만드는 시연 영상의 **씬 구성(환경)·에이전트 움직임·카메라·기술 규격**을 처음부터 구성할 수 있게 정의.
> 이 영상은 `assets/sim.mp4` 로 넣으면 데모의 **로봇 촬영 모달(정비사 앱)과 로봇 HUD 카메라 화면**에서 자동 재생된다 (없으면 정지 이미지 폴백 — 이미 구현됨).

---

## 0. 이 영상이 증명하는 것 (한 문장)

> **"로봇이 블레이드 한 개를 같은 조건(각도·거리·조명)으로 3면 촬영하고, 품질이 미달하면 파라미터를 보정해 다시 찍는다."**

- 12단계 중 **6단계(촬영 수행)** 를 재현하고, **판단②(품질검증 루프)** 를 움직임으로 한 번 보여주는 것이 차별점.
- 로봇 필요성 서사(D-008)와 직결: 사람이 찍으면 매번 달라지는 것을, 로봇은 **똑같이 반복**한다 — 영상에서 3개 포즈가 "정확히 멈추고, 정확히 되돌아오는" 것 자체가 메시지.
- 형상 정밀도보다 **흐름 가시성 우선** (업무지시 v1 원칙 유지). 막히면 프리미티브 대체.

## 1. 씬 구성 (환경·배경)

배경 컨셉: **엔진 오버홀 샵의 블레이드 검사 코너.** 격납고 아님, 기체 아님 — 분해된 부품이 스탠드에 거치된 실내 작업 공간.

| 요소 | 사양 (제안) | 프리미티브 대체안 |
| --- | --- | --- |
| 바닥 | `plane` — 어두운 회색(#2a2e35 근처). 데모 UI 배경(#0a0e14)과 톤 맞춤 | 그대로 |
| 검사 스탠드 | 작업대 박스 0.6×0.6×0.75m, 짙은 청회색 | 박스 1개 |
| 블레이드 고정구 | 스탠드 위 소형 블록(바이스 느낌) 0.12×0.12×0.08m | 박스 1개 |
| **HPC 블레이드** | GrabCAD 등 STL (라이선스 메모 필수). 수직 거치, 에어포일이 카메라 쪽 | **비틀린 얇은 박스**(0.04×0.012×0.22m, twist ~15°) 또는 얇은 박스+살짝 기울임. 색: 티타늄 회색, 금속 광 |
| **Indy7** | 뉴로메카 ROS 패키지 URDF (`indy7.urdf`). 스탠드 옆 0.5~0.6m, 원기둥 페데스탈(h 0.4m) 위 | 6링크 프리미티브 암 (최후 수단 — URDF 우선) |
| 카메라 헤드 | Indy7 플랜지에 소형 박스(IndyEye 상징) + 렌즈 원기둥 | 박스 1개 |
| 조명 | PyBullet 기본광 + `lightDirection` 지정 (블레이드에 하이라이트 오게) | — |

**스케일 참고:** 실제 HPC 블레이드는 손가락 크기(수 cm)지만, 화면 가시성을 위해 **20~25cm급으로 확대 허용**. 발표에서 물으면 "흐름 가시화를 위한 연출 스케일"로 답 (수치 정밀 재현이 목적이 아님을 문서로 남김 — 본 문서가 그 기록).

**Moby(모바일 베이스)는 씬에서 제외.** 오버홀 샵 시나리오는 스탠드 옆 고정 작업이라 팔만 있으면 충분하고, '이동중' 상태는 데모 가동보드가 이미 표현한다. 로봇 구성(Indy7+Moby) 발표 자료와 충돌 아님 — 시뮬은 6단계(촬영)만 재현한다고 명시.

## 2. 에이전트 움직임 — 타임라인 (총 ~23초, 루프)

구현은 **물리 시뮬 불필요.** 관절 키프레임을 정하고 프레임마다 `resetJointState`로 보간 재생(ease-in-out)하면 된다. IK 정밀도 필요 없음 — 포즈 6개를 손으로 튜닝.

| 구간 | 시간 | 동작 | 연출 포인트 |
| --- | --- | --- | --- |
| A. 대기 | 0–2s | 홈 포즈 정지 | 루프 시작점 (마지막 포즈와 동일해야 루프가 안 튐) |
| B. 접근 | 2–5s | 홈 → **리딩엣지 포즈** 이동 | 부드러운 보간. 카메라 헤드가 블레이드 전연을 정면으로 |
| C. 촬영 1 | 5–7s | 2초 완전 정지 | **정지가 곧 촬영.** 정지 프레임 0.2초간 화면 밝기 +15% (플래시 연출, 렌더 후 numpy로) |
| D. 이동 | 7–10s | **압력면 포즈**로 (블레이드 측면 1) | 손목 회전이 보이게 — 각도가 바뀌는 걸 관절 움직임으로 |
| E. 촬영 2 | 10–12s | 2초 정지 + 플래시 | |
| F. 이동 | 12–15s | **흡입면 포즈**로 (반대 측면) | |
| G. 촬영 3 | 15–17s | 2초 정지 + 플래시 | |
| **H. 판단② 연출** | 17–21s | 흡입면에서 **살짝 물러났다가, 거리 −5cm·각도 +8° 보정한 포즈로 재접근** 후 재촬영(플래시) | **이 4초가 영상의 차별점.** "미달 사유를 파라미터에 보정해 재촬영 — 단순 retry 아님"(판단②)의 시각화. 두 번째 포즈가 첫 번째와 *분명히 다르게* 보여야 함 |
| I. 복귀 | 21–23s | 홈 포즈로 복귀 → 루프 | A와 동일 포즈에서 종료 |

**요구컷 3면**(리딩엣지·압력면·흡입면)은 데모 화면 문안과 정확히 일치한다 — 정비사 앱 촬영 단계에 "촬영할 부위 — 요구컷 3: 리딩엣지 · 압력면 · 흡입면"이라고 이미 떠 있으므로, 영상의 3정지가 그 문안의 실연이 된다.

## 3. 카메라·렌더

**메인 카메라 = 3인칭 고정 1대** (로봇+블레이드 전경).
- 타깃: 블레이드 중심. 거리 ~1.5m, pitch −15°, yaw는 전체 길이 동안 **10° 정도만 아주 느리게** 회전 (정적이면 죽어 보이고, 많이 돌면 산만).
- 프레이밍: **블레이드+로봇 팔이 화면의 60% 이상.** 재생 화면이 모달에서 420×210px로 작게 보이므로, 넓은 샷은 아무것도 안 보인다.
- 렌더: `p.getCameraImage(1920, 1080)` 오프스크린 (DIRECT 모드; GUI 불필요).

**서브 산출물 (선택, 슬라이드용): POV 스틸 3장.** 각 촬영 정지 시점에 카메라 헤드(플랜지 링크) 기준 `getCameraImage`로 "로봇이 본 화면" 1장씩 → 발표 슬라이드에서 "같은 조건 3컷" 비교 그림으로 사용. 영상에 편집해 넣지는 않는다(모달이 작아서 컷 전환은 산만).

**영상에 자막·라벨·bbox를 넣지 말 것.** CAM-01 라벨, REC 점, 스캔 애니메이션, 결함 bbox는 **데모 HTML이 영상 위에 오버레이**한다. 영상은 깨끗한 원본이어야 한다.

## 4. 기술 규격·파이프라인

| 항목 | 값 |
| --- | --- |
| 해상도·fps | 1920×1080, 30fps (발표 규격과 동일) |
| 길이 | 20~25초, **루프 전제** (muted·autoplay·loop로 재생됨) |
| 인코딩 | `ffmpeg -framerate 30 -i frame_%04d.png -c:v libx264 -pix_fmt yuv420p -crf 23 sim.mp4` |
| 용량 | **20MB 이하 권장** — 서버가 파일을 통째로 읽어 보내는 구조라 크면 데모 로딩이 느려짐. 발표 영상 원본(500MB급)을 그대로 넣지 말 것 |
| 파일 위치 | `assets/sim.mp4` — 넣기만 하면 연동 끝. 코드 수정 불필요 |
| 확인 방법 | `node server.js <pw>` → 정비사 앱에서 작업 선택 → "로봇에게 촬영 맡기기" → 영상 재생 + "PyBullet 시뮬" 배지 확인. robot.html도 동일 |

파이썬 골격 (핸드오프 §4 유지 + 위 타임라인 반영):
```python
import pybullet as p, numpy as np
p.connect(p.DIRECT)
# 씬 로드: plane, 스탠드 박스, 블레이드(STL or 프리미티브), indy7.urdf
KEY = {  # 초 → 관절각 6개 (손 튜닝)
  0: HOME, 5: LEADING_EDGE, 10: PRESSURE_SIDE, 15: SUCTION_SIDE,
  19: SUCTION_RETAKE,   # 판단② 보정 포즈 (거리 -5cm, 각도 +8°)
  23: HOME }
for f in range(23*30):
    t = f/30
    q = ease_interp(KEY, t)            # 키프레임 사이 ease-in-out 보간
    for j,a in enumerate(q): p.resetJointState(robot, j, a)
    w,h,rgb,*_ = p.getCameraImage(1920,1080, viewMatrix=VM(t), projectionMatrix=PM)
    img = np.reshape(rgb,(1080,1920,4))[:,:,:3]
    if is_shot_frame(t): img = np.clip(img*1.15,0,255)   # 촬영 플래시
    save_png(img, f)
```
